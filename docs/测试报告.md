## 附录 A: 快速开始指南

### 安装依赖

```bash
cd construction_management_system_Backend
pip install -r requirements.txt
```

### 配置环境变量

编辑 `.env` 文件，添加:

```env
GEMINI_API_KEY=your_api_key_here
GEMINI_MODEL=gemini-1.5-flash
```

### 初始化数据库

```bash
python init_db.py
```

### 启动服务器

```bash
uvicorn app.main:app --reload
```

### 访问 API 文档

打开浏览器访问: http://localhost:8000/docs

### 账号准备

系统不内置演示账号，需先创建：

- 监理：`POST /api/auth/register` → `{full_name, email, password, role:"site_supervisor"}`
- 工人：`POST /api/auth/register/worker`
- 登录：`POST /api/auth/login`（OAuth2 表单，`username`=邮箱）

> 仅 worker / site_supervisor 两类账号，无 admin 账号与管理员后台。
