## 1. 系统概览

BuildSmart 是一个现代化的建设工程管理系统，采用前后端分离架构，基于 FastAPI（Python）和 Flutter 技术栈构建。

### 技术架构
- **后端**: FastAPI + SQLAlchemy + SQLite
- **前端**: Flutter (支持 Android/iOS/Web)
- **数据库**: SQLite (支持 PostgreSQL 扩展)
- **地理位置**: GPS 地理围栏 + Haversine 公式

### 2.4 GPS 地理围栏考勤 (Attendance)

#### 核心功能
- 工人进场打卡 (GPS 验证)
- 工人退场打卡
- 心跳位置上报
- 自动离场检测与取消打卡
- 今日考勤汇总统计
- 迟到/早退标记

#### 地理围栏逻辑
- 使用 Haversine 公式计算两点间距离
- 进场验证：必须在地理围栏内
- 离场验证：记录最终距离
- 自动取消：连续2次越界心跳后自动取消打卡状态

#### API 接口
- `POST /api/attendance/check-in` - 进场打卡
- `POST /api/attendance/checkin` - 兼容版进场打卡
- `POST /api/attendance/heartbeat` - 心跳上报
- `POST /api/attendance/check-out` - 退场打卡
- `POST /api/attendance/checkout` - 兼容版退场打卡
- `GET /api/attendance/worker/{wid}/today` - 获取工人今日考勤
- `GET /api/attendance/today` - 获取今日考勤汇总

#### 数据模型
```sql
attendance_logs:
  - attendance_id (主键)
  - worker_id (外键)
  - project_id (外键)
  - check_in_time
  - check_out_time
  - in_lat (进场纬度)
  - in_lng (进场经度)
  - out_lat (退场纬度)
  - out_lng (退场经度)
  - in_distance_m (进场距离中心，单位：米)
  - out_distance_m (退场距离中心，单位：米)
  - status (checked_in/checked_out/left_early/absent/rejected)
  - last_heartbeat_time
  - last_heartbeat_lat
  - last_heartbeat_lng
  - out_of_fence_count (连续越界次数)
```

## 5. 核心算法与逻辑

### 5.1 GPS 距离计算 (Haversine Formula)
```python
def distance_m(lat1, lng1, lat2, lng2):
    EARTH_RADIUS_M = 6371000.0
    p1 = math.radians(lat1)
    p2 = math.radians(lat2)
    dphi = math.radians(lat2 - lat1)
    dlambda = math.radians(lng2 - lng1)
    a = sin(dphi/2)^2 + cos(p1)*cos(p2)*sin(dlambda/2)^2
    return 2 * EARTH_RADIUS_M * asin(sqrt(a))
```

### 5.2 AI 工人匹配算法
- 基础分数：45分
- 工种匹配：+35分
- 今日在场：+15分
- 迟到在场：+5分
- 安全培训：+3分
- 安全员身份：+2分
- 最高得分：99分

## 7. 系统限制与边界

### 当前限制
1. 数据库：SQLite（生产环境建议 PostgreSQL）
2. 认证：仅 Supervisor 角色，无细粒度权限控制
3. 存储：无文件上传功能（仅存储路径字符串）
4. AI：无外部 LLM 集成（本地简单匹配算法）
5. 通知：无实时通知推送机制
6. 报表：基础 KPI 数据，无高级分析图表
7. 预算：无预算与成本管理功能
8. 材料：无材料与设备管理功能
