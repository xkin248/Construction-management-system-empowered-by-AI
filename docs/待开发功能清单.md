## 1. 功能模块一：Google Gemini AI 集成

### 1.1 业务需求边界

#### 1.1.1 AI 智能助手聊天
- 用户可以与 AI 助手进行自然语言对话
- AI 助手可以回答关于项目管理、工程问题、安全规范等问题
- 支持上下文对话记忆
- 支持多轮对话

#### 1.1.2 智能任务分析与建议
- 自动分析任务内容，建议合适的工人
- 根据历史数据预测任务完成时间
- 自动生成任务分解建议

#### 1.1.3 日报智能生成
- 根据当日考勤、任务进度、问题记录自动生成日报草稿
- AI 润色日报内容
- 自动提取关键信息

#### 1.1.4 安全风险智能识别
- 分析问题描述，识别潜在安全风险
- 提供安全建议和预防措施
- 安全知识问答

#### 1.1.5 数据智能分析
- 自然语言查询项目数据
- 自动生成数据洞察报告
- 异常数据识别与告警

### 1.2 技术规范

#### 1.2.1 后端接口规范
```python
# API 接口设计
POST /api/ai/chat - AI 对话
POST /api/ai/task/analyze - 任务智能分析
POST /api/ai/report/generate - 智能生成日报
POST /api/ai/safety/analyze - 安全风险分析
POST /api/ai/data/query - 自然语言数据查询
```

#### 1.2.2 数据模型
```sql
ai_chat_sessions:
  - session_id (主键)
  - supervisor_id (外键)
  - created_at
  - updated_at

ai_chat_messages:
  - message_id (主键)
  - session_id (外键)
  - role (user/assistant)
  - content
  - created_at
  - tokens_used
```

#### 1.2.3 技术栈选择
- **LLM**: Google Gemini API (gemini-1.5-pro/gemini-1.5-flash)
- **SDK**: google-generativeai Python 包
- **Prompt 管理**: 结构化提示词模板
- **Token 统计**: 内置 token 计数

#### 1.2.4 异常处理
- API 调用失败重试机制（最多3次）
- Token 超限降级处理
- 超时保护（30秒）
- 降级到本地简单逻辑

### 1.3 依赖关系
- 前置依赖：用户认证系统、任务管理、问题管理
- 外部依赖：Google Gemini API 访问权限
- 配置依赖：API Key 配置

## 2. 功能模块二：文件管理系统

### 2.1 业务需求边界

#### 2.1.1 文件上传
- 支持图片、PDF、Word、Excel 等常见格式
- 支持多文件同时上传
- 文件大小限制（单文件最大 50MB）
- 文件类型白名单控制

#### 2.1.2 文件分类
- 项目文档
- 安全记录
- 施工图纸
- 验收报告
- 其他附件

#### 2.1.3 文件管理
- 文件列表查看
- 文件预览
- 文件下载
- 文件删除
- 文件重命名
- 文件移动分类

#### 2.1.4 文件关联
- 关联到项目
- 关联到任务
- 关联到问题
- 关联到日报

#### 2.1.5 图片处理
- 图片自动压缩
- 生成缩略图
- EXIF 信息读取（拍摄时间、GPS 位置）

### 2.2 技术规范

#### 2.2.1 存储方案选择
**推荐方案：本地文件存储 + PostgreSQL（数据库记录）**

理由：
- 项目当前使用 SQLite，可平滑迁移到 PostgreSQL
- 本地存储部署简单，无额外服务依赖
- 适合中小规模项目
- 便于备份和迁移

**备选方案：Firebase Storage**

适用场景：
- 需要跨设备实时同步
- 需要 CDN 加速
- 项目已有 Firebase 基础设施

#### 2.2.2 后端接口规范
```python
POST /api/files/upload - 上传文件
GET /api/files - 获取文件列表
GET /api/files/{fid} - 获取文件信息
GET /api/files/{fid}/download - 下载文件
GET /api/files/{fid}/preview - 文件预览
DELETE /api/files/{fid} - 删除文件
PUT /api/files/{fid} - 更新文件信息
POST /api/files/{fid}/link - 关联文件到实体
```

#### 2.2.3 数据模型
```sql
files:
  - file_id (主键)
  - original_name
  - stored_name
  - file_path
  - file_size (bytes)
  - mime_type
  - file_category (document/safety/drawing/report/attachment)
  - thumbnail_path (图片文件)
  - uploaded_by (外键)
  - project_id (外键，可空)
  - created_at
  - updated_at

file_links:
  - link_id (主键)
  - file_id (外键)
  - entity_type (project/task/issue/report)
  - entity_id
  - created_at
```

#### 2.2.4 技术实现
- **文件上传**: FastAPI UploadFile
- **图片处理**: Pillow (PIL)
- **文件类型验证**: python-magic 或扩展名白名单
- **文件路径**: 按日期组织 (uploads/YYYY/MM/DD/)

#### 2.2.5 异常处理
- 文件大小超限拒绝
- 文件类型不支持拒绝
- 磁盘空间检查
- 上传失败回滚

### 2.3 依赖关系
- 前置依赖：项目管理、用户认证
- 外部依赖：Pillow (图片处理)
