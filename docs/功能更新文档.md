# BuildSmart 建设管理系统 - 功能更新文档

**版本**: v2.0  
**日期**: 2026-07-23  
**作者**: BuildSmart Team

---

## 概述

本次更新主要完成了三个核心功能模块的开发：

1. **文件管理系统** - 支持文件上传、管理、关联和预览
2. **Gemini AI 集成** - AI 聊天助手、任务分析、日报生成等
3. **通知系统** - 实时通知推送、通知管理和设置

---

## 1. 文件管理系统

### 1.1 新增功能

#### 文件上传
- 支持图片（JPG/PNG/GIF/WEBP）、PDF、Office 文档等
- 文件大小限制：50MB
- 自动生成缩略图（图片文件）
- 按日期组织文件存储路径

#### 文件管理
- 文件列表查看（支持按项目、分类筛选）
- 文件下载
- 文件删除
- 文件信息更新（文件名、分类、关联项目）

#### 文件关联
- 支持将文件关联到项目、任务、问题等实体
- 查看文件关联关系
- 取消文件关联

### 1.2 新增 API 接口

| 方法 | 路径 | 描述 |
|------|------|------|
| POST | /api/files/upload | 上传文件 |
| GET | /api/files | 获取文件列表 |
| GET | /api/files/{id} | 获取文件详情 |
| GET | /api/files/{id}/download | 下载文件 |
| GET | /api/files/{id}/thumbnail | 获取缩略图 |
| PUT | /api/files/{id} | 更新文件信息 |
| DELETE | /api/files/{id} | 删除文件 |
| POST | /api/files/{id}/link | 关联文件到实体 |
| GET | /api/files/{id}/links | 获取文件关联列表 |
| DELETE | /api/files/{id}/links/{link_id} | 取消关联 |

### 1.3 数据模型变更

#### 新增表
- `files` - 文件信息表
- `file_links` - 文件关联表

### 1.4 配置要求

在 `.env` 文件中确保以下配置：

```env
# （无需特殊配置，文件存储在本地）
```

目录结构：
```
construction_management_system_Backend/
├── uploads/          # 原始文件存储
└── thumbnails/       # 缩略图存储
```

## 2. Gemini AI 集成

### 2.1 新增功能

#### AI 聊天助手
- 支持多轮对话
- 对话历史记录
- Token 使用统计
- 系统预设提示词（建筑工程专业知识）

#### 任务智能分析
- 基于任务内容推荐合适的工人
- 分析工人技能匹配度
- 考虑今日出勤状态
- 任务优先级建议

#### 日报智能生成
- 自动汇总项目进度
- 统计出勤情况
- 列出待解决问题
- 生成结构化日报草稿

#### 安全风险分析
- 分析安全事件描述
- 评估风险等级
- 提供处理建议

### 2.2 新增 API 接口

| 方法 | 路径 | 描述 |
|------|------|------|
| GET | /api/ai/chat/sessions | 获取聊天会话列表 |
| GET | /api/ai/chat/sessions/{id} | 获取会话详情 |
| DELETE | /api/ai/chat/sessions/{id} | 删除会话 |
| POST | /api/ai/chat | 发送聊天消息 |
| POST | /api/ai/tasks/analyze | 分析任务 |
| POST | /api/ai/reports/generate | 生成日报 |
| POST | /api/ai/safety/analyze | 安全风险分析 |

### 2.3 数据模型变更

#### 新增表
- `ai_chat_sessions` - AI 聊天会话表
- `ai_chat_messages` - AI 聊天消息表

### 2.4 配置要求

在 `.env` 文件中添加：

```env
# Google Gemini API 配置
GEMINI_API_KEY=your_actual_api_key_here
GEMINI_MODEL=gemini-1.5-flash  # 或 gemini-1.5-pro
```

获取 API Key：https://makersuite.google.com/app/apikey

### 2.5 依赖更新

`requirements.txt` 新增：
```
google-generativeai==0.7.0
```

## 3. 通知系统

### 3.1 新增功能

#### 通知管理
- 查看通知列表（支持筛选未读）
- 标记单个通知为已读
- 一键标记全部已读
- 删除通知
- 未读消息计数

#### 通知类型
- `attendance` - 考勤异常提醒
- `task_overdue` - 任务逾期提醒
- `task_assigned` - 任务分配通知
- `issue` - 新问题报告
- `safety` - 安全事件告警
- `daily_report` - 日报提醒

#### 通知设置
- 按类型开关通知
- 支持邮件通知（预留接口）
- 支持推送通知（预留接口）

#### WebSocket 实时推送
- 实时接收新通知
- 自动更新未读计数

### 3.2 新增 API 接口

| 方法 | 路径 | 描述 |
|------|------|------|
| GET | /api/notifications | 获取通知列表 |
| GET | /api/notifications/unread-count | 获取未读计数 |
| GET | /api/notifications/{id} | 获取通知详情 |
| PUT | /api/notifications/{id}/read | 标记已读 |
| PUT | /api/notifications/read-all | 全部标记已读 |
| DELETE | /api/notifications/{id} | 删除通知 |
| GET | /api/notifications/settings | 获取通知设置 |
| PUT | /api/notifications/settings | 更新通知设置 |
| WS | /api/ws/notifications | WebSocket 连接 |

### 3.3 数据模型变更

#### 新增表
- `notifications` - 通知表
- `notification_settings` - 通知设置表

### 3.4 依赖更新

`requirements.txt` 新增：
```
websockets==12.0
```

## 4. 部署说明

### 4.1 后端部署

1. 更新依赖
```bash
cd construction_management_system_Backend
pip install -r requirements.txt
```

2. 配置环境变量（参考 `.env` 文件）

3. 初始化数据库（自动创建新表）
```bash
python init_db.py
```

4. 启动服务
```bash
uvicorn app.main:app --reload
```

### 4.2 API 文档

启动后访问：
- Swagger UI: http://localhost:8000/docs
- ReDoc: http://localhost:8000/redoc
