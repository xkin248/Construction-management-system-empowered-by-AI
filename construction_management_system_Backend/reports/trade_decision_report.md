## 9. 字段含义与报表用途

| 字段 / 指标 | 含义 |
| --- | --- |
| total_decisions | 日志中的全部判定数，含跳过；等于每次 AI 决策一行。 |
| decided | 有最终工种（final_trade 非空）的判定数，是各类比例的分母。 |
| source | 判定来源：rule（规则）/ classifier（分类器）/ semantic（语义仲裁） / llm（Gemini 兜底）/ explicit（人工指定）/ skip（跳过）。 |
| final_trade | 本次判定最终采用的工种；skip 行为空。 |
| skip_reason | 判定放弃的原因文本，用于定位规则/模型的盲区。 |
| llm_used | 是否调用了 Gemini 兜底；与 final_trade 非空叠加即为“采纳”。 |
| was_overridden / override_trade | 主管事后改派标记与实际改派成的工种，构成“预测 vs 真值”标注对。 |
| elapsed_ms | 单次判定耗时（毫秒）。 |
| confidence | 判定置信度（0~1），低于阈值视为低置信。 |

**报表用途**：

1. **上线质量监控**：看 source 分布与低置信占比，判断生产流量是否仍依赖兜底或频繁跳过。
2. **兜底性价比评估**：采纳率过低说明 Gemini 兜底在烧延迟却不产出，应检查提示词或候选集。
3. **错误率观测**：改派率是线上最真实的人工纠错信号，可替代离线指标做回归监控。
4. **训练数据回流**：导出的改派样本可直接作为标注数据回灌训练集，下一轮重训即覆盖这些盲区。
5. **性能基线**：平均耗时作为接口 SLA 的参照。
